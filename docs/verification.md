# v0.1.0 验证记录

平台：macOS / Apple Silicon。使用 Textual 6.12.0，FFmpeg 外部安装。

| 用户目标 | 可观察结果 | 验证 |
|---|---|---|
| 快速区别完整与缺失数据 | 五类状态、覆盖率与详情；未知长度不被判为完整 | 真实缓存扫描、生成媒体测试 |
| 鼠标或键盘操作 | 点击扫描、列表选择、状态筛选和搜索 | Textual Pilot 测试；macOS Terminal 实测 |
| 单个预览 | 完整数据生成临时 MP4，在默认播放器显示 | 实际 Terminal → QuickTime，播放时间向前推进 |
| 单个与批量导出 | 目录里生成可解码文件；既有文件不覆盖 | Pilot 点击测试、FFmpeg 全程解码、真实缓存导出 |
| 多种格式 | MP4 / MKV / 原格式；不兼容编码转 MP4 | 实际 MP4 与 VP9 WebM 测试 |
| 公开可用 | 中文 README、项目图标、真实终端截图、安装包 | 本机打包执行 `--version` 和 `--scan --deep` |

9 项测试通过。真实缓存扫描合并重复资源后得到 130 项（56 项完整、74 项缺片）；这是开发时的一次本地快照，非通用保证。截图与测试素材由 FFmpeg 生成，不包含这些私人缓存。测试时自动启动播放器的调用被替换，实际播放器流程另外在本机验证。

当前边界：支持 macOS 原生 Telegram 的 MediaBox 格式；不支持 Qt Telegram Desktop 的 tdata。没有下载或补片功能。终端预览通过外部默认播放器；建议窗口至少 85 × 36。发布二进制仅覆盖 macOS arm64，需要额外安装 FFmpeg，未签名或公证。
