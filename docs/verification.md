# v0.2.0 验证记录

## 按需浏览开发版（2026-10-30）

本轮按用户三点要求继续调整：扫描后不自动选中视频，重新扫描重置缩略图开关；仅点击视频行或键盘激活条目才展开预览，勾选导出不触发预览，播放准备期间切换视频只展示最后点击的条目。目录选择与自动扫描按钮相邻；自动定位继续限定支持的 macOS 原生 MediaBox 格式。

新增秒数上下限筛选，与大小、名称和类型条件取交集。时长优先使用视频流信息，缺失时回退容器，忽略无效值；大小按索引范围与实际文件长度的交集统计。新增回归覆盖时长边界与未知值、缺片详情关闭、扫描后恢复纯列表、勾选不触发预览和连续点击不同视频。

在 `feat/on-demand-cache-browser` 延续实现：启动空闲；用户点击后扫描；缩略图与预览默认关闭；视频／疑似动图筛选；按索引已缓存字节筛选与排序，未知大小不冒充文件长度；筛选后保留勾选并显示隐藏数量。自动定位兼容两种原生账户目录层级，手动目录沿用同一扫描逻辑。

修复了切换筛选后缩略图队列漏项、不可解码缩略图重复尝试、预览准备期间无法关闭、过期预览临时文件残留，以及未打开预览时无法查看导出失败原因的问题。重新扫描时关闭预览并丢弃旧缩略图任务的结果。

33 项自动测试通过，使用自制 FFmpeg 测试画面，覆盖上述状态流转，以及实际视频帧、进度、完整性复验、导出和 CLI 兼容性。本轮未读取真实缓存视频。Apple Silicon 独立应用构建成功。真实窗口验收因电脑控制未获准操作 Cache Lens 而未完成，自动测试使用 Qt 无窗口后端，不能替代人工布局验收；既有 v0.2.0 验收记录如下。

## v0.2.0 已发布版本

平台：macOS / Apple Silicon；Python 3.12、PySide6 / Qt 6.12.0，外部 FFmpeg。

核心体验：普通终端里按编号选择、预览和导出；复杂浏览在独立 Mac 窗口完成。硬约束：原缓存只读、缺片和未知长度不导出、不覆盖已有文件。GUI 使用 Qt 独立窗口；预览验证后生成临时 MP4；命令行预览仍调用系统默认播放器。

| 用户目标 | 可观察验收条件 | 结果 |
|---|---|---|
| 简洁命令行 | 启动显示摘要与分页列表，编号进入单项操作，无全屏面板 | 实际 Terminal 完成单项和批量导出；截图只裁去系统标题栏及空白 |
| 非交互使用 | JSON 扫描保持兼容；单项／全部导出可用于脚本，失败返回非零 | CLI 测试及打包后 `--version`、`--scan --deep` 验证 |
| 独立 Mac 窗口 | 双击 `.app`，左右列表／播放器，底部导出栏 | 打包应用真实启动，原生窗口截图 |
| 查找与选择 | 缩略图、搜索、状态筛选、排序、勾选 | GUI 测试；真实窗口勾选两项后显示已选 2 项 |
| 内嵌播放 | 有实际视频帧，时间推进，可暂停和拖动进度 | 自动测试收到有效帧；Mac 窗口从 00:00 播放到 00:20，拖动回 00:05 |
| 单项和批量导出 | 实际输出可解码文件；源变化时失败并给原因 | GUI 单项／两项批量、Terminal 单项／批量均通过输出全程解码；自动测试覆盖源变化失败提示 |
| 真实缓存 | 合并重复项，完整性判断，实际导出后解码 | 本机 CLI 复扫 172 项：96 完整、76 缺片；数据仅是本次快照 |
| 首次目录授权 | 新应用经 macOS 允许后读取 Telegram 目录 | 系统 AppData 授权日志确认允许；独立 `.app` 已读取 Telegram 容器内不含视频的目录。真实视频的 GUI 缩略图、播放与导出未验证；演示目录的完整 GUI 流程已通过 |
| 公开材料 | 自身图标、真实截图、公开样例，无私有缓存 | 图标和截图随仓库保存；演示素材由 FFmpeg 生成 |

12 项自动测试通过，覆盖核心媒体处理、CLI 和 GUI。GUI 测试使用无窗口后端；真实 Mac 窗口验收单独执行。首次系统权限等待时界面会说明原因，不能把等待授权误报为扫描完成。

2026-10-30 补充：用户允许目录访问，但要求不读取真实视频内容。收到该限制后，仅检查目录属性及系统授权记录，未对真实视频生成缩略图、播放或导出。上述真实缓存 CLI 数量来自限制前的验证快照；后续功能验证使用自制测试素材。

边界：只支持 macOS 原生 Telegram 的 MediaBox，不支持 Telegram Desktop 的 tdata；不能下载或补片。默认每次解码／导出超时 600 秒，可调整。GUI 关闭时会等待当前处理结束再清理预览文件。发布包仅验证 macOS arm64，不包含外部 ffmpeg/ffprobe 命令行工具；未做 Apple 开发者签名或公证。
