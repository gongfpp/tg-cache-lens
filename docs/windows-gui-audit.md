# Windows GUI 视觉检查

使用 Windows 原生 Qt 后端、合成视频和 1120×760、900×640 窗口，检查列表、播放器和片段恢复面板。按视觉层级、对齐、文本可读性、状态与操作反馈四项逐一检查；不使用私人缓存。

- 列表按字段排列，缓存时间与其他列使用相同的行对齐；点击列标题切换排序方向。窗口缩小时文件 ID 会省略，悬停可查看完整内容。
- 状态使用文字和颜色共同表达；未确认长度不会标为完整。
- 恢复界面的预览直接嵌入右侧，选中片段与合并导出操作位于同一面板。
- 窄窗口中新增时间列会挤压文件 ID，因此增大展开预览时的列表初始宽度；用户仍可拖动分隔条调整。

本检查基于合成数据生成的原生窗口画面及控件几何测试；不同 Windows 缩放比例、主题和字体仍需后续覆盖。
