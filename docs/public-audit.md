# v0.2.0 公开检查

检查范围：当前公开源文件、从首次 v0.1.0 提交到当前改动的 Git 文件清单、README 素材、Python 分发包和 Mac 安装包。

- 私人缓存、真实扫描报告、导出视频、运行日志和本机路径保留在忽略目录，未进入版本管理。
- GUI 截图来自实际 `.app`，CLI 截图来自真实终端，裁去包含用户名的系统标题栏与空白；画面均来自自制测试信号。没有用示意图代替运行截图。
- 检查凭据模式、私人绝对路径、真实缓存标识和不应公开的媒体文件；没有发现阻止公开的问题。
- 项目代码和原创图标使用 MIT。Qt / PySide6 / Shiboken 使用 LGPLv3 动态链接分发；安装包带许可证、版权声明、上游源码位置及重建说明。Qt 播放后端带 LGPL FFmpeg 库；外部扫描／导出用的 FFmpeg 命令行工具不打包。
- 公开仓库只有首次发布以来的可检查历史；不改写旧提交。生成素材、代码与依赖许可分别核对。
- Release 提供 SHA-256 校验文件，上传后重新下载核对。发布时的验证边界见 `verification.md`。

这是针对上述范围的检查结论，不代表对未支持的缓存格式或所有运行环境的保证。
